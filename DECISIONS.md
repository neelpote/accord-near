# Decisions

- Product name: Accord. User delegated naming.
- Public repository: neelpote/accord-near. User approved public visibility and reuse/publication rights.
- Testnet only; no mainnet keys, calls or funds.
- Native Rust contract enforces amount, recipient, period, lifetime cap, delegate and cancellation. Native test NEAR is an explicit prototype denomination, not USDC.
- Preserve Daemon attribution and baseline.
- Loops event near-hackathon exists. Evaluation needs login; no enrollment/submission is authorized.

- User approved adding NEAR AI Cloud using free credits, then explicitly asked to skip credit setup after HTTP 402. Keep the adapter paused and do not imply live AI output works. No credit purchases/top-ups.
- Product-facing branding is Accord. Accurate upstream provenance and the baseline/new-work distinction remain; reused code is not represented as written from scratch.
- Active default scripts/Compose use NEAR and a fresh database. Legacy EVM startup/schema commands are explicitly prefixed and archived deployment files are inactive.
- Individual third-party wallet vendor UIs are outside the automated fixture's evidence. The actual standard connector/API/testnet boundary is tested.
