# Storylines

## Selected: The signature that never happened
Device: result first. Form: evidence-led match cuts between real UI and a forensic document/terminal world.
First two seconds: the real BLOCK result fills the frame; “0 signatures” lands beside it. We rewind to the clean invoice, watch a real owner approve a valid purchase, then change only the vendor document and watch the model redirect the recipient. The exact same payment boundary stops the malicious proposal. The film returns to real native and Ethereum wallet exits.
Beats: BLOCK hook → valid purchase → one poisoned document → model redirect → refusal → both wallet proofs → owner exit → Accord.
Look: actual product ivory #efeee9 and charcoal #20221f; grotesk sans, large orange/red accents reserved for authority and refusal; no fake dashboards.
Sound: restrained electronic pulse, real-click accents, one impact on refusal and an intentional short drop before the zero-signatures payoff.

## Alternative: Operator's desk
Device: one operator's task. Form: an almost continuous trip from workspace to agreement to evidence.
First two seconds: a funded agreement waits on an actual warning. The owner inspects, approves and sees a receipt; a new malicious vendor instruction creates the failure case. Calmer and more tutorial-like; less immediate than the selected hook.

## Alternative: Follow 0.001 NEAR
Device: one amount travelling across the system. Form: repeated numeric match cuts from budget to receipt to blocked proposal.
First two seconds: 0.001 NEAR splits into “authorized” and “attempted”. The same amount stays fixed while the receiver changes. More abstract and less obviously real than the selected evidence-first treatment.
